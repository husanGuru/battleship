# battleship

## Run Locally

Clone the project (only dev branch, or clone all branches and checkout to dev)

```bash
  git clone --branch dev --single-branch git@github.com:husanGuru/battleship.git 
```
Go to project directory

```bash
  cd project-directory
```

Open 2 terminals in the project-directory  (for client and server)

---

In the 1st terminal: 
Go to server directory and run server

```bash
  cd server
  npm run dev
```

Install dependencies

```bash
  npm install
```

---

In the 2nd terminal: 

Go to client directory and run client
```bash
  cd client
  npm run start
```
